# Holy Tree Chase（聖夜のオーナメント抽選会）

[ゲームを開く](https://kazuyamasaki.github.io/holy-tree-chase/)

週次チームミーティングのアイスブレイク担当を決める、3Dクリスマスツリー・マーブルラン抽選ミニゲームです。
巨大クリスマスツリーの頂上から、参加メンバーの名前が入った3Dオーナメントボールを一斉投下し、最初に最下部の「黄金の煙突」へ飛び込んだ1名が当選します。

## 特徴

- **スプレッドシート対応**：名前の列をコピー＆ペーストするだけで即スタート（2〜20名対応、重複・空行自動チェック）
- **木製玩具をテーマにした3Dマーブルラン**：雪の村を描いた箱絵から、彫刻風のツリーと真鍮のレールへ。ベルや可動ゲートを抜け、黄金の煙突に最初に入った人を発表します。WebGLが使えない場合も、同じレースをコース図で観戦できます。
- **星の追い風**。先頭がらせんの47%と78%に達すると、先頭から距離が開いた玉が短時間加速します。差が大きいほど強い風を受け、順位表には追い風を受けてから上げた順位が「追い風 ↑2」のように表示されます。
- **Google Meet 画面共有向け最適化**：高コントラストな名札表示、リアルタイム順位表＆実況テロップ、視点切替（自動追尾／全体俯瞰）、画質「軽量（30fps）」モード、別タブ移動時の自動一時停止
- **BGMと効果音**。初期曲は「Holy Tree Run」です。ページを開いて約1.5秒で再生し、右上のプルダウンで「Golden Spiral」「Golden Toy Run」にも切り替えられます。自動再生が制限された場合は「BGMを再生」を押してください。BGMのON/OFFは次回も引き継ぎます。効果音はページを開くたびにOFFになり、右上の「効果音 OFF」を押すとONになります。

## GitHub Pages での公開方法

`npm run build` で生成された以下のファイルをそのままリポジトリに配置して GitHub Pages を有効化してください。

```text
index.html         ← アプリ本体（3D描画・物理・UI・SE内蔵）
favicon.svg        ← ファビコン
audio/
  bgm.json         ← BGM設定ファイル（後から曲を追加可能）
  Holy Tree Run.mp3
  Golden Spiral.mp3
  Golden Toy Run.mp3
```

## BGM音声ファイルの追加方法

1. `audio/` フォルダに `.mp3` / `.ogg` / `.wav` / `.m4a` ファイルを配置します。
2. `audio/bgm.json` の `tracks` に以下のような項目を追加します。`label` がプルダウンの曲名になります。初期曲を変える場合は `defaultTrack` にその曲の `id` を指定します。

```json
{
  "id": "jingle",
  "label": "Christmas Swing",
  "file": "christmas_swing.mp3",
  "volume": 0.15
}
```

3. GitHub Pagesやローカルサーバーではページを再読み込みすると反映されます。`index.html` を直接開く配布版でも曲目を更新する場合は `npm run build` を実行し、`audio/` をHTMLと一緒に配布します。

## ローカル開発・検証コマンド

```bash
npm test      # 名簿パース・物理完走・公平性テスト（2〜20名）
npm run build # index.html / favicon.svg をビルド
npm run serve # http://127.0.0.1:4176 でローカル確認
```
